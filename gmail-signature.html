How to install in Gmail

1. Click anywhere inside the dashed box below, then press Ctrl/Cmd + A followed by Ctrl/Cmd + C to copy the rendered signature.

2. In Gmail, open Settings > See all settings > General. Scroll to Signature, click Create new, paste, then save at the bottom of the page.

3. Under Signature defaults, set the new signature for both For new emails and On reply / forward so it always attaches.

The logo image is embedded directly in the signature as base64, so it always renders even before recipients accept "load remote content." No external hosting needed.
